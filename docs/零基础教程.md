# 零基础教程：从零把项目跑起来（照着做就行）

> 本教程假设你**没碰过命令行**。每一步都告诉你「点哪里、输什么、看到什么才算对」。
> 全程不用联网、不用写代码，只需要**复制粘贴**。

> ⚙️ **环境已经装好了，不用你做任何配置**：本机 Python 3.11 里装齐了全部依赖，项目也安装过了。
> ⚠️ 本机默认 `python` 指向 3.12（缺依赖），**所有命令统一用 `py -3.11`**。
> **不需要建虚拟环境**；项目里也不保留 `.venv/`，直接走系统 3.11。

---

## 第 0 步：先搞清楚一个东西——「终端」是什么

「终端」（也叫「命令行」「命令提示符」）就是一个**黑底白字的窗口**，你在里面打字、电脑执行。

你不需要理解它，只需要知道：**打开它 → 复制粘贴命令 → 按回车**，三步。

---

## 第 1 步：打开终端

1. 按键盘 **`Win` 键**（左下角带四个小方块的键）
2. 直接打字：`cmd`（或「命令提示符」）
3. 按 **回车**，会弹出一个黑窗口

> 出现 `C:\Users\你的用户名>` 这样的字样，就说明终端开好了。

---

## 第 2 步：进入项目文件夹

在黑窗口里，**复制下面这行**（选中文字 → Ctrl+C），然后在黑窗口里**右键粘贴**，按回车：

```
cd G:\姜涛_复试项目整合\02_VLM-Doc-Deploy_票据表单信息抽取与边缘部署
```

> 回车后，光标前面会变成 `G:\姜涛_复试项目整合\02_VLM-Doc-Deploy_票据表单信息抽取与边缘部署>`，说明进去了。

---

## 第 3 步：启动服务（这一步会加载模型，等 15~30 秒）

复制下面这行，粘贴，回车：

```
py -3.11 -m src.serving.app
```

**接下来会看到一堆日志刷屏**，最后出现这几行才说明成功了：

```
模型加载完成，服务就绪
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8000
```

> ⚠️ **不要只看「服务就绪」**：如果 8000 端口被占用，日志会先打印「服务就绪」，随后才报 `Errno 10048`。
> 必须再开一个终端执行 `curl http://127.0.0.1:8000/health`，返回 `{"status":"ok","model_loaded":true}` 才算真正就绪。
> ⚠️ **这个窗口千万别关**，关了服务就停了。先让它一直开着。

---

## 第 4 步：再开一个终端，测试一张图

**关键点**：刚才那个窗口要一直开着，现在要**再开一个新窗口**。方法和第 1 步一样（`Win` → `cmd` → 回车）。

在新窗口里，复制粘贴回车，进入项目目录：

```
cd G:\姜涛_复试项目整合\02_VLM-Doc-Deploy_票据表单信息抽取与边缘部署
```

然后复制下面这行，粘贴回车：

```
curl -X POST -F "file=@data/raw/sroie/img/000.jpg" http://127.0.0.1:8000/extract
```

**如果成功**，会返回这样一段 JSON（就是模型从票据图里抽出的 4 个字段）：

```
{"company":"BOOK TA.K(TAMAN DAYA) SDN BHD","date":"25/12/2018","address":"NO.53 55,57 & 59, JALAN SAGU 18, TAMAN DAYA, 81100 JOHOR BAHRU, JOHOR.","total":"9.00"}
```

这串东西的意思：模型把一张收据图片，抽出了 **公司名 / 日期 / 地址 / 金额** 四个字段。

---

## 第 5 步：换一张图再试（演示现场用的就是这招）

复制粘贴回车：

```
curl -X POST -F "file=@data/raw/sroie/img/042.jpg" http://127.0.0.1:8000/extract
```

会返回另一张图的字段。说明**这不是回放、不是死的**——喂不同的图，出不同的结果。

---

## 第 6 步：收尾——关掉服务

1. 切回**第一个窗口**（那个一直开着的）
2. 按 **`Ctrl + C`**（同时按），服务就停了
3. 两个黑窗口都可以直接点右上角 × 关掉

---

## 常见问题（照这个排查）

| 遇到的情况 | 怎么办 |
|---|---|
| 回车后提示「不是内部或外部命令」 | 说明命令没复制全，或不在正确目录。先重做第 2 步的 `cd` 命令 |
| 提示 `No module named ...`，或提示找不到 `python` | 说明命令没走 3.11。重开一个终端敲 `py -3.11 -V`，能显示 `Python 3.11.x` 就对了；不要创建或激活虚拟环境 |
| 第 3 步一直没出现「服务就绪」 | 模型加载慢，再等 1 分钟；还不行就截图发我 |
| 第 4 步返回一堆英文报错 | 多半是**第一个窗口的服务没起成功**。回去看第一个窗口最后有没有「服务就绪」 |
| `curl` 提示找不到 | 先执行 `curl --version` 确认；Windows 10/11 一般自带 curl。仍没有就用 PowerShell 的 `Invoke-WebRequest` 代替 |
| 返回的 JSON 里日期和图片对不上 | 正常，这是模型的**零样本**预测，个别字段会有 OCR 噪声，不是 bug |

---

## 演示现场的最小演示流程（背下来）

1. 提前 15 分钟：开终端 → `cd` 进目录 → `py -3.11 -m src.serving.app` → 等到「服务就绪」
2. 开第二个终端 → `cd` 进目录 → `curl .../img/042.jpg` → 出结果
3. 讲解：「这是一张它**从没见过**的收据，现场抽出了四个字段」
4. 收尾：第一个窗口 `Ctrl+C`

> 全程只读图片、只跑推理，不写任何项目文件——这就是「零脏数据」。
