> 核心原则：**只做「零脏数据」的动作，全程可离线，任何一步失败都不影响主线。**

## 展示中（主线 15~20 分钟，全部零脏数据）

### ① 开场定位（30 秒）

> 多模态 VLM 文档/票据结构化抽取 + 8GB 边缘部署优化。和第一个项目 SciTriple（文本微调）
> 拼成「非结构化 → 结构化信息抽取」的主线：SciTriple 做文本训练，这个做图片抽取 + 系统部署。

### ② 静态主线讲解（10~12 分钟，只读文件，零风险）

按顺序打开现成文件，**不跑任何脚本**：

1. **README** — 项目定位 + 技术选型
2. **`reports/quant_summary.md` + `quant_pareto.png`** — 核心成果表（数字门面）
3. **`reports/accuracy_positioning.md`** — 精度定位（提前堵「比 SOTA 低」的质疑）
4. **`reports/error_analysis_bnb4.md`** — 误差分析（82.97% 正确 / 10.26% 噪声 / 6.61% 语义错 / 幻觉仅 0.08%）
5. **`reports/xfund_generalization.md`** — 跨域泛化（证明不是背 SROIE 四字段）
6. **`reports/w3_batching.md` / `w3_kvquant.md` / `w3_profile.md` / `w4_serving.md`** — 系统感四点（批处理 / 视觉 token / KV 量化 / 压测）

### ③ 现场 live demo（2~3 分钟，零脏，唯一「动手」环节）

切回**已预热好的服务**，现场 curl 一张 PPT 里**没展示过**的真实收据（显得是现场、不是回放）：

```bash
curl -X POST -F "file=@data/raw/sroie/img/042.jpg" http://127.0.0.1:8000/extract
```

拿到 JSON 后，打开 `data/raw/sroie/key/042.json` 对照，说「现场这张图和金标一致」。

> 没传 `log_file`），**不落任何文件**；进程退出后 GPU 显存由系统自动回收。

### ④ 数字问答（被问就答，统一口径）

| 被问 | 答 |
|---|---|
| 量化收益 | bnb4 vs bf16：norm F1 **−1.7pp**、延迟中位 **×2.85** / 均值 **×2.8**、峰值显存 **−52%** |
| 「SROIE 不是 626 张吗」 | 原始 626，剔除 2 个计时异常样本后 624，剔除不影响精度结论（那 2 张预测本就正确），属数据清洗常规操作 |
| 「为什么比 SOTA 0.95 低」 | 见 `accuracy_positioning.md`：官方 SOTA 是「训练过 + OCR 先验」的序列标注；我是「零样本 3B 4bit」生成式，0.93 norm 在小模型零样本已是上游 |
| 「零样本跨域行吗」 | XFUND 中文表单 50 张零样本 normalized F1 = **0.4072**，证明模型懂通用「字段→值」抽取，不是背 SROIE 四字段 |

## 兜底方案（演示最怕的四种翻车）

| 情况 | 应对 |
|---|---|
| **没网** | 全程离线：模型在 `models/`、数据在 `data/`、服务本地 `127.0.0.1`，直接说「全程无需联网」 |
| **现场机器不是你的 / 没 GPU** | 静态讲解（主线②）完全够，独立于 demo；demo 改成「读 `app.py` 讲架构」+ 提前录 30 秒 demo 视频兜底 |
| **评审要看「现场重跑」** | 诚实说「完整评估 624 张 × 2 方法要 1 小时+，现场不现实」；折中给「跑起来」= 起服务 + 单张 curl |
| **服务起不来**（OOM/依赖） | 考前 15 分钟预热就是为提前暴露；即使 demo 失败，静态主线②不受影响，别慌 |

## 数字速查卡（演示前熟悉）

- **量化（全量 624 张）**：bf16 = exact 0.8451 / norm 0.9501 / 均值 19.6s / 中位 17.1s / 峰值 7799MB / 权重 6132MB；bnb4 = 0.8304 / 0.9330 / 7.1s / 6.0s / 3710MB / 2302MB
- **量化收益**：精度 −1.7pp、延迟中位 ×2.85、均值 ×2.8、峰值显存 −52%
- **误差（bnb4）**：correct 82.97% / noise 10.26% / wrong 6.61% / hallucination 0.08%
- **视觉 token**：84 张 >1 万 token（最大 16307），longest_edge=2M 约束后 ≤2669，总量削减 51%；无约束大图直接 OOM（15.97GB）
- **批处理**：0.178 / 0.228 / 0.247（吞吐单调升，代价只在显存）；KV 量化 int8 无损 / int4 崩
- **压测**：QPS 0.18 / 0.22 / 0.22，P95 5.9 / 9.1 / 18s（并发只涨延迟不涨吞吐）
- **跨域 XFUND（50 张零样本）**：字段级 normalized F1 = **0.4072**（P 0.43 / R 0.39）
